Masuk ke ruang admin

Halaman ini menyimpan perubahan langsung ke repositori GitHub Anda. Untuk itu diperlukan kunci akses (token) yang hanya tersimpan di perangkat ini.

  1. Buka github.com/settings/personal-access-tokens/new
  2. Isi nama token, misalnya Admin Undangan, dan pilih masa berlaku.
  3. Pada Repository access pilih Only select repositories, lalu pilih repositori undangan.
  4. Pada Permissions → Repository permissions, ubah Contents menjadi Read and write. Opsional: Pages menjadi Read-only.
  5. Klik Generate token, salin, lalu tempel di bawah.
